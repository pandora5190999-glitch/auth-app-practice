# auth-app-practice

## 概要
COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。


## 使用技術
- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL


## 学んだこと
- Fortifyをインストール・FortifyServiceProviderを登録する
- リダイレクト先を設定する
- ミドルウェアを設定する

## 動作確認
ブラウザで確認。その後、コマンドを入力してユーザー登録動作を確認し、ログアウト後の動作も確認。

## 手詰まりになったこと
動作確認の時にエラーが出て、sampleを見ながら手直しはしたが、初めて振り返りながらほぼ自力で作成できた。
